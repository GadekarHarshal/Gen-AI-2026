# NPTELPicker – Sample User Questions

These questions will be used to test our AI course recommendation assistant.

## 1. Course Information

**Q1.** What topics are covered in Week 9 of the IIT Delhi Computer Architecture course?

**Q2.** Is the Joy of Computing using Python course suitable for beginners?

## 2. Credits and Duration

**Q3.** How many credits are recommended for an 8-week NPTEL course?

**Q4.** How many credits can I earn by completing a 12-week NPTEL course?

## 3. Course Recommendations

**Q5.** I am a Second Year Computer Engineering student. Suggest one 12-week core course and one 4-week placement-useful course.

**Q6.** Suggest an NPTEL course for a student interested in Artificial Intelligence and Machine Learning.

## 4. Course Comparison

**Q7.** Compare Cloud Computing by IIT Kharagpur and Software Testing by IIIT Bangalore.

**Q8.** Which is better for placements: Python Programming or Data Structures and Algorithms?

## 5. Credit Transfer and Planning

**Q9.** Will Savitribai Phule Pune University accept NPTEL courses for credit transfer?

**Q10.** I can study for 6 hours per week. Suggest an NPTEL course that matches my available study time and placement goals.

---

## Purpose

These questions will help us evaluate whether NPTELPicker can:

- Understand student queries.
- Find relevant course information.
- Recommend suitable courses.
- Explain course duration and credits.
- Compare different courses.
- Provide useful study plans.
- Identify questions that require official verification.
