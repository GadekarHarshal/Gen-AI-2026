# NPTELPicker – Resume Description

**Project:** NPTELPicker – AI-Powered NPTEL Course Discovery and Selection Assistant

**Technologies:** Python, FastAPI, Streamlit, Google Gemini, LangChain, LangGraph, ChromaDB, Docker, GitHub Actions.

### Key Contributions

- Developed an AI-powered NPTEL course discovery system to help students find suitable courses based on academic branch, learning goals, credits and course information.
- Implemented a Retrieval-Augmented Generation (RAG) pipeline using LangChain, ChromaDB and Gemini embeddings, along with a LangGraph agent for contextual question answering and course planning.
- Integrated FastAPI, Streamlit, Docker and GitHub Actions CI/CD; implemented response caching and Gemini performance monitoring, recording a sample API latency of 945.88 ms with 60 tokens processed.
